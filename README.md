An entry for the make.fun bounty
[Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0):
coin one new English word and define it in a single clear line.

## The entry

> **notifidget** — the urge to check your phone for a notification that never came.

77 characters, one line. *Notifidget* (notification + fidget) names the gap
everyone lives with daily: the reflexive phone-check for a buzz that never
happened. Sayable on first sight, spellable as it sounds, memorable because
the reader has done it in the last hour.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

`main.ts` (Node 22, standard library only) writes the entry to
`entry.txt` in the output directory (`/output` by default). It runs twice
byte-identically and uses no network.

## Candidates considered

See `candidates.txt` — five words drafted, four rejected after a live search
showed they already existed (`tabnesia`, `snackward`, `roomnesia`, `byewalk`
in archaic senses), leaving `notifidget`.
